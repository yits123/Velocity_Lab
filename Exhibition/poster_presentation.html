03 System Design & Live Architecture

SprintGate uses a Headless Dual-Fire Architecture combining ultra-fast direct radio packets with local Wi-Fi telemetry:

  • Node A (0m Start Gate): ESP32 with microsecond hardware interrupt, active-low buzzer, and PN532 RFID tag reader for instant athlete badge recognition.
  • Node B (Finish Gate): ESP32 with OLED status screen, embedded WebSocket server (port 81), and offline buffer queue.
  • Sand-Ballasted Quadrapods: 4-legged PVC stand with 85cm tip-to-tip span filled with dry sand. Centers optical beam at 90–100cm (pelvic center of mass) to eliminate false triggers from swinging arms or feet.
  • ESP-NOW Primary Link: Sub-millisecond peer-to-peer radio sync (0.82 ms latency) bypassing Wi-Fi congestion.
